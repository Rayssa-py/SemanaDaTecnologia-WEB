## 📌 Sobre o Projeto

A **Semana de Tecnologia e Cultura** é uma página informativa desenvolvida como atividade prática para a disciplina de **Desenvolvimento Web** do **Instituto Federal do Ceará (IFCE)**, com base nas orientações e requisitos definidos na [documentação da atividade](https://thmz.notion.site/css3-semana-de-tecnologia?pvs=143).

O objetivo principal do projeto é aplicar na prática os conceitos fundamentais de estruturação com **HTML5** e estilização com **CSS3**, criando uma interface acessível, organizada e semântica.

## 🚀 Estrutura da Página

* **Cabeçalho (`<header>`):** Apresentação do evento e menu de navegação.

* **Menu de Navegação (`<nav>`):** Links internos de navegação ágil para cada seção (`#sobre`, `#programacao`, `#atividades`, `#inscricoes`).

* **Seção Sobre (`#sobre`):** Texto descritivo sobre o propósito do evento acompanhado de imagem ilustrativa com texto alternativo (`alt`).

* **Seção Programação (`#programacao`):** Tabela organizadora (`<table>`) contendo horários, nomes das atividades e locais.

* **Seção Atividades (`#atividades`):** Destaque em cartões (`<div>`) apresentando título, resumo e links externos para mais informações de cada oficina/workshop.

* **Seção Inscrições (`#inscricoes`):** Informações sobre participação e link direcionando para o portal institucional do IFCE.

* **Rodapé (`<footer>`):** Créditos dos desenvolvedores e identificação da instituição.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível da página.

* **CSS3:** Estilização, layout e padronização visual.

## 📁 Como Executar Localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/Rayssa-py/SemanaDaTecnologia-WEB.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd SemanaDaTecnologia-WEB
   ```

3. Abra o arquivo `index.html` em seu navegador de preferência.
