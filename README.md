# 🌐 Semana de Tecnologia e Cultura — IFCE

Projeto prático desenvolvido para a disciplina de **Desenvolvimento Web**, com o objetivo de construir a página de um evento fictício utilizando conceitos fundamentais de **HTML5** e **CSS3**.

---

## 📌 Sobre o Projeto

A **Semana de Tecnologia e Cultura** é uma página informativa criada para apresentar a programação, oficinas e formulário de inscrição do evento. 

O projeto aborda a estruturação semântica da Web, navegação interna via IDs, exibição de dados em tabelas, organização de cartões (*cards*) e links externos para a instituição e atividades.

---

## 🚀 Funcionalidades e Estrutura do Site

- **Cabeçalho (`<header>`):** Apresentação do evento e menu de navegação interna.
- **Menu de Navegação (`<nav>`):** Links rápidos com rolagens diretas para as seções da página.
- **Seção Sobre (`<section id="sobre">`):** Texto explicativo sobre os objetivos do evento e imagem ilustrativa.
- **Seção Programação (`<section id="programacao">`):** Tabela organizadora com horários, atividades e locais.
- **Seção Atividades (`<section id="atividades">`):** Exibição em formato de *cards* (`<div>`) com títulos, descrições e links externos para mais informações.
- **Seção Inscrições (`<section id="inscricoes">`):** Informações sobre inscrições e direcionamento para o portal do IFCE.
- **Rodapé (`<footer>`):** Créditos dos desenvolvedores e dados institucionais.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout e responsividade.
